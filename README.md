# 轻言输入法

macOS 原生中文 / 英文 / 离线语音输入法，当前为 **0.1.16 开发预览版**。

目标：Apple Silicon，macOS 14 及以上。当前在 macOS 26.6.2 / Xcode 26.5 上编译。

## 开始使用

当前电脑已安装 0.1.16 到 `~/Library/Input Methods/LocalInput.app`，并已注册、启用；已在系统输入源列表中确认「轻言输入法」名称和「轻言」双字图标。安装保留当前输入源选择。

1. 在菜单栏输入源中选择 **轻言输入法**。若菜单没有显示，可在「系统设置 → 键盘 → 文本输入 → 编辑」中添加；必要时注销并重新登录。
2. 第一次使用语音，打开输入法菜单中的「轻言设置与语音状态…」，或打开 `LocalInput.app/Contents/Helpers/LocalInput Voice.app`，点击「授予麦克风权限」，在系统弹窗中允许。系统可能将此权限列在「轻言输入法」名下。也可直接点击「测试语音」，授权后开始录音。
3. 在 TextEdit 新建文档，输入 `nihao`，按空格得到「你好」。
4. 单按 Shift 切换英文；尚未确认的拼音按原始字母输入。例如输入 `hello` 后按 Shift，得到 `hello`，不会确认中文候选。已经确认的文字保持原样。按住 Shift 输入大写字母不会触发切换。
5. 在轻言输入法启用时，按住 **Control + Option + Space**，看到“正在聆听”后说话；说话过程中，识别文字会直接在输入框中逐步出现和修正；松开停止录音，完成最后一次校正并定稿，无需 Enter。Esc 取消。

## 已实现

- Rime 全拼、简体输出、整词 / 整句候选、本地词频学习。中文主词库采用 [雾凇拼音](https://github.com/iDvel/rime-ice) 的常用字表、基础词库、扩展词库、腾讯词向量及杂项词库，包含「老登」「显眼包」「情绪价值」等词。
- 内置八股文（octagram）简体语法模型 `zh-hans-t-essay-bgw`，按上下文组句。它是概率模型，个别词组可能反而变差。
- 空格选择当前候选、1–5 数字选词、鼠标选择、上下键选择、减号 / 等号或 Page Up / Page Down 翻页。
- 「常用词」列表同时用于打字：自动按字推导拼音写成 Rime 自定义短语表，专有名词排在词库候选之前。
- 英文直接输入、大小写和常用应用快捷键透传。
- 独立语音辅助进程；内置 Whisper Small 多语言 Q5_1 模型，无需 API key。
- 自动语言检测，以及手动中文 / 英文模式。中文转写统一为简体。
- 按住说话时在输入框内显示临时转写，后续识别替换同一段文字，松开后校正并定稿。Esc 取消并撤回仍由输入法持有的临时文字；原有选中文字会恢复。
- 录音达到约 0.8 秒后开始尝试识别，后续约每 0.35 秒尝试更新，每次最多运行一个识别任务；识别完成后立即通知输入法显示；切换到轻言会在后台提前加载本地模型（不会启动麦克风）；首次模型加载、长录音或机器繁忙仍会增加显示延迟，不保证逐字即时输出。很短的片段可能暂时没有结果；主要说中文时可将“语音语言”设为“中文”，省去自动判断语言的耗时。
- 不支持选区查询的输入框在候选面板显示过程结果，松开后一次性输入。移动光标、切换焦点或继续打字会停止后续更新；目标应用可能自行保留已显示的预编辑文字。
- 最长 60 秒录音，静音 / 过短音频拒绝、可取消识别、请求超时处理。
- 输入会话、前台应用和选区校验；切换窗口会取消当前语音流程，避免异步转写写入其他输入框。
- 设置页：语言、Shift 切换开关、候选字号、自定义本地模型、语音测试与手动复制。
- 可选 Jev 云端上下文选词：对 Rime 前 20 个候选按拼音覆盖范围分组，完整匹配优先，组内按 Jev 评分降序排列，显示「✦ Jev」和 0–100 分，保留本地候选即时响应。

麦克风使用系统默认设备。

## Jev 上下文选词

在「轻言设置与语音状态… → Jev 选词」中保存自己的 TypeSafe API Key，并开启「启用 Jev 云端选词」。已有设置默认关闭此功能。点击「测试示例」会实际调用 Jev，显示 `汽车 youxiang`、`我现在 youxiang`、`请发到我的 youxiang` 的各项分数和降序结果；预期首位分别是「油箱」「又想」「邮箱」，实际效果需用自己的 Key 验证。

- 使用 [TypeSafe Score](https://docs.typesafe.ai/primitives/score) 和 [HTTP API](https://docs.typesafe.ai/api)，模型为 `jev-latest`。一次请求包含每个候选各自的 Score 问题，全部采用同一套五级语境衔接标准。先按真实拼音覆盖范围排列：完整覆盖当前输入优先，其余按覆盖长度从长到短；仅在相同覆盖范围内，将 Jev 的 0–4 加权分数换算为 0–100 分后降序排列，同组同分保留 Rime 原顺序；分数表示适配程度，不是正确率或置信度。不生成新词。
- 首屏候选即时显示；停顿 180 毫秒后开始请求，网络请求最多等待约 2 秒。当前候选池的每项都会评分，按覆盖范围分组、组内按分数排序后每页显示 5 项。数字键、空格和鼠标对应显示的词；上下键选择，减号 / 等号或 Page Up / Page Down 在评分池内翻页仍保留分组和组内降序。超过前 20 项后继续显示 Rime 原生候选。
- **覆盖范围**由 Rime 高亮候选的提交预览读取，上下文查询后恢复原高亮，不试选或上屏。`youxiang` 的「油箱／邮箱／又想」完整覆盖，「游戏／有戏」只覆盖 `youxi`、留下 `ang`，「有」只覆盖 `you`、留下 `xiang`。部分候选标注「部分」，不会凭较高 Jev 分数越过完整匹配。光标位于拼音中间或覆盖无法可靠获取时保留原生候选。
- 输入变化、手动导航、切换输入框或模式后取消待处理请求，并在应用结果前再次核对前台应用、输入客户端、光标位置和候选状态。已经发送的请求可能仍产生 API 费用；不在按键路径自动重试。
- 在输入框支持读取光标前文且停留于第一页时请求；前文为空也会评分，但不虚构语境，同分保留本地顺序。不支持上下文读取的输入框继续使用本地候选，面板会显示原因；请求过程中显示「Jev 评分中」，失败、超时也会显示回退状态。Jev 的评分范围为当前前 20 项候选，不能保证每个同音词都已被词库召回。
- **数据发送**：开启并配置 Key 后，光标前最多 128 个 UTF-16 字符、当前拼音、预编辑文字和最多 20 个候选会发送到 TypeSafe。Key 单独保存在 `~/Library/Application Support/LocalInput/typesafe-credential.json`（权限 0600），不会写入普通设置或日志。可在设置中关闭功能或移除 Key。
- 没有 Key、网络超时、服务错误、缺少任一候选的评分或分数格式不合法时，保持 Rime 本地候选。语音识别和语音纠错不使用 Jev。

## 更换语音快捷键

打开输入法菜单中的「轻言设置与语音状态…」，在 **语音快捷键** 一栏点击当前按键，再录制新的按键；或打开 **快捷选项**，选择 F5、右 Option 或 Fn。也可以点「恢复默认」回到 Control + Option + Space。

- **功能键**：F1–F20 可以单独绑定，例如 F5，也支持搭配修饰键。
- **修饰键**：支持单独使用左 / 右 Control、Option、Command、Shift 和 Fn。录制时按下后松开即可，左右键分别识别。
- **按住说话**：所有绑定都按下开始、说话时逐步显示文字、松开停止并定稿。组合键中松开主键或任一必要修饰键都会停止。旧版单按 / 长按设置保留按键，但统一改为按住说话。
- 修饰键录音期间搭配其他按键或鼠标操作会取消语音；若将某一侧 Shift 设为语音键，该侧单按将优先触发语音，另一侧仍可切换中英文。
- 普通字母、数字、空格和编辑键仍需搭配 Control、Option 或 Command，避免占用正常打字。
- Esc 取消录制；点击其他控件或切换窗口也会取消，不更改原快捷键。
- 设置保存后，下次语音输入立即使用新快捷键，无需重新安装或重启。菜单和录音提示会显示当前组合键。
- 快捷键仅在轻言输入法启用时生效。系统已经占用的按键可能无法送达输入法，需换一组；常见的 Spotlight / 输入源切换组合键会被拒绝。Fn / 地球键及 F 键可能被系统听写、表情或媒体控制占用，可在系统键盘设置中调整；应用不会自动更改这些系统设置。
- 升级旧版会保留原有设置，默认仍为 Control + Option + Space。进行中的录音继续使用启动时的快捷键。

## 常用词与本地纠错

打开设置的 **语音纠错** 标签页：

- **常用词提示**：每行填写一个专有名词，自动保存。最多 40 个词，每词最多 40 字、合计 400 字。提示直接送入 Whisper 解码，不做强制替换。
- **同时用于打字**：同一份列表会写成 Rime 自定义短语表。每个词的拼音按单字读音推导，多音字取词库标注的高频读音，最多保留 4 种拼法。含字母、数字或表情的词条（如 `Qingyan`）不生成拼法，只用于语音；超过 12 个字的词条也跳过。
- **生效时机**：改完列表切回输入框即生效，不需要重新部署或重启；切换时会重建输入会话，正在输入的拼音请先上屏。
- **本地 AI 轻度纠错**：可选开关。实时显示仍走语音识别；松开后才用本地模型检查一次错字和标点。目标是不润色、不扩写，但不能保证完全不改错。
- **等待与回退**：纠错最多等待 4 秒，长于 800 字、服务不可用、超时或改动不满足保护规则时直接保留原文。检测数字、部分单位、否定词和词库中已正确出现的名称，并限制编辑幅度；这些规则并不等于语义正确性保证。
- **继续输入**：处于“正在本地轻度纠错”时开始打字或点击，若原选区仍有效，就提交原始识别结果，并取消迟到的纠错。Esc 此时仍取消整段语音。
- **恢复原文**：纠错定稿后，在原输入框立即按 Esc 可替换回原文。继续输入、移动光标或切换窗口后，停止自动恢复；可在纠错设置页查看并复制原文。原文和结果最多保留 10 分钟。

此电脑已经准备了本地模型。移到另一台 Mac 时，先安装 Ollama，并运行 `ollama pull qwen3:4b-instruct`，然后在设置中点击“检查模型”。纠错服务使用单独的 `127.0.0.1:11435` 端口，启动时设置 `OLLAMA_NO_CLOUD=1`；仅接受本地模型，HTTP 请求禁用代理、缓存与重定向。不会改动默认 Ollama 服务配置，也不会自动删除已有模型。模型在内存中预热保留约 30 分钟；退出辅助应用时会停止由它启动的服务。

## 隐私与本地数据

0.1.3 修复了旧版点击授权时退出的问题：macOS 将嵌套语音辅助进程的麦克风请求归属到外层输入法，旧版外层应用缺少用途声明。现已同时在两个应用中声明，并在构建时检查。若之前点过拒绝，设置中的按钮会显示「打开麦克风权限设置」。

- 语音识别及语音纠错在本机进行；Whisper 模型和拼音词库随应用提供。可选的语音纠错功能使用本机 Ollama 和另行下载的 Qwen3 4B Instruct（约 2.5GB），仅初次下载权重需要联网。单独开启 Jev 选词后，拼音输入的有限上下文会发送到 TypeSafe，详见上节。
- 原始录音只在内存中处理，不保存为音频文件。
- 输入法与语音辅助进程通过当前用户专用目录交换状态与临时转写。目录权限 0700，文件权限 0600。
- 转写上屏或取消后清理临时会话文件；异常退出留下的旧文件会在之后启动时清理。
- 设置窗口最多保留最近一次转写 10 分钟，支持立即清除。它不是长期历史记录。
- Rime 学习词库和设置保存在 `~/Library/Application Support/LocalInput`。不记录完整按键日志。
- 常用词生成的 `Rime/custom_phrase.txt` 与 `Rime/custom_phrase.stamp` 保存在同一目录，权限 0600，内容由设置中的列表决定，手工修改会被覆盖。
- 只有点击「复制文字」或「复制原文」才写入剪贴板；正常上屏使用 InputMethodKit。

## 构建、测试和安装

在本目录运行，依赖 Xcode 与 Python 3，无需 Homebrew 或云服务：

```sh
python3 Scripts/bootstrap.py
bash Scripts/build.sh
bash Scripts/test.sh
bash Scripts/install.sh
```

`bootstrap.py` 使用 `dependencies.lock.json` 中的版本和 SHA-256 下载依赖。`build.sh` 检查下载文件校验和，编译 Swift / Objective-C、预编译词库、打包模型并进行本机 ad-hoc 签名。

### 更新雾凇词库

雾凇由上游持续维护；轻言按固定提交打包词库，未开启 Jev 时打字仍然离线。以下命令从上游取得最新词库、更新版本与校验和，通过构建和测试后安装：

```sh
python3 Scripts/update-dictionary.py
bash Scripts/build.sh
bash Scripts/test.sh
bash Scripts/install.sh
```

目前需要主动执行更新，没有后台定时下载。更新脚本只导入词库和归属声明，不执行上游脚本；也支持 `--revision <完整提交号>` 指定版本。安装完成后重新启动输入法进程才能加载新词库。

轻言沿用现有全拼配置和 `luna_pinyin_simp` 内部方案 ID，实际主词库为 `rime_ice`；保留 `luna_pinyin` 用户学习库和个人常用词。原朙月字典仅用于个人常用词的拼音推导，不再作为主候选词库。未引入雾凇完整方案的 Lua 功能与快捷键。

产物：`build/LocalInput.app`。它是本机开发构建，尚未完成 Developer ID 签名与公证。

卸载：

```sh
bash Scripts/uninstall.sh
```

卸载会禁用轻言并将应用移到废纸篓，保留个人词库和设置。若已运行的输入法仍被 macOS 保留，需要注销后重新登录。

## 验证结果与限制

详见 `VALIDATION.md`。真实 Rime 词库测试、语法模型与自定义短语的端到端测试、输入状态测试、中文 / 英文音频文件转写、静音拒绝、原生设置视图渲染、签名验证和系统注册已完成。

**尚未完成真实麦克风到目标输入框的全流程验收，以及 TextEdit、浏览器、微信、VS Code、终端的手动兼容性检查。** 本次桌面自动控制服务超时，因此这些项目不能记为通过。

语法模型改善了整句同音选词，但不保证正确：同一批对照样本中 `qingbangwochayixiahangban` 由「航班」变成了「行板」。把词加进「常用词」是更确定的做法。语音识别的中文专有名词仍存在同音误识别，中英混说样本的英文部分出现明显错误。建议先使用单一语言短句，并在自动输入后检查文字。当前不包含双拼、五笔、英文预测、云端识别或 AI 改写。

## 结构

- `Sources/InputMethod`：InputMethodKit 控制器、候选面板、输入法入口。
- `Sources/Bridge`：librime Objective-C 接口。
- `Sources/Companion`：设置界面、录音、离线识别、语音辅助进程。
- `Sources/Shared`：私有 IPC、设置、Shift 与异步结果状态逻辑、常用词到自定义短语表的转换。
- `Tests`：真实词库与状态回归测试。
- `Scripts`：下载、构建、安装、卸载、输入源注册。

上游：[InputMethodKit](https://developer.apple.com/documentation/inputmethodkit)、[librime](https://github.com/rime/librime)、[librime-octagram](https://github.com/lotem/librime-octagram)、[rime-octagram-data](https://github.com/lotem/rime-octagram-data)、[whisper.cpp](https://github.com/ggml-org/whisper.cpp)。第三方声明见 `THIRD_PARTY.md` 和应用内 `Contents/Resources/Licenses`。
